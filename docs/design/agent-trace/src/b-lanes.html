Who did what, when

Bands under each workerSupervision state from the z0 FSM vocabulary: Dispatched or Resumed, Running, Stalled, Verifying, DraftPR, then Completed or Interrupted. Verifying and DraftPR are read from tool calls, so they are estimates.
ElbowsA dispatch drops from the orchestrator into the worker's first call. A report rises from a worker's last call. An interrupted worker never reports back, so it ends in a cross with no return line.
CountersCalls are exact. Tokens and cost are per-worker totals from Hermes, spread over the replay in proportion to calls, so mid-run values are approximate (≈).
