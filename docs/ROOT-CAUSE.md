# Dash root-cause gate map

This is a **source-backed prevention inventory**, not a declaration of a common proven root cause. One row per requested PR/issue, with one **primary** bug class even when a PR changed several areas. Merged fix PRs describe changes; open issues can describe *hypotheses* or an *audit to perform*, not confirmed failures. No new device, CI or runtime execution was performed for this document.

**Evidence** below is limited to the linked PR bodies/diffs or issue reports. **Inference** is a proposed explanation for gate escape, not a proven defect mechanism. `unknown` means the linked text did not state how the defect was originally discovered. Every path under “Missing gate” is a **proposed test location**, not an assertion that the file exists or is wired to CI.

## Missing-gate priorities

By **classified work items** (30 total, **not 30 confirmed regressions**), the top three missing *gate families* are:

1. **A — rendered/native accessibility journeys: 16 items** (includes 14 prospective audit issues).
2. **C — actual native app/device journeys and trace gates: 10 items** (layout, navigation, lifecycle, reload, native bundle, frame-time).
3. **B — paired bridge/contract/reconciliation integration fixtures: 4 items**.

These are frequency priorities, not severity scores. A covers rendered ARIA plus accessible native actions/focus. C includes native screenshots, lifecycle, Metro reload and frame-time telemetry, none of which is replaced by a pure test. B injects real process/socket failures and race ordering rather than just typed or mocked responses. Future CI wiring is owned by Hermes; do not edit CI in this lane.
