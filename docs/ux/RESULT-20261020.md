## Libraries picked

- Keep FlashList. It already virtualizes Dash chats and exposes measured layouts and index navigation.
- Use `react-native-marked` 8.3.2 through its node-rendering hook. It is maintained, uses the same parser family as OMP/opencode, and does not add a nested vertical list.
- Use Prism 1.30.0 with a limited grammar set, plus Expo Clipboard 57.0.2. Code stays selectable. Unsupported languages remain plain text.
- Reuse Gesture Handler, Reanimated, Worklets and Expo haptics for the rail. No new native module or development-client rebuild is required.

The selected parser/highlighter engines measured 25,420 bytes gzip in a standalone browser build. This is not a full-app or native bundle-size delta. See [the survey](oss-survey-20261020.md) and [pinned sources](sources-20261020.json).

## Test on your phone

1. Open a long real chat in transcript mode. Scrub up and down. Check the preview and one haptic tick per crossed prompt.
2. Scroll up while a reply streams. Confirm the text stays in place. Tap Latest and confirm new output follows again.
3. Read and copy TypeScript, shell and diff blocks. Scroll long code horizontally. Expand thinking and tool activity.
4. Open the keyboard, send a prompt, close/reopen the chat and change tabs. Confirm the composer and latest reply remain above the keyboard.
5. Check running/error chat order and the approvals link. Preview fixtures do not authorize real approvals.

No real phone, IME behavior, physical haptics or real model turn was verified here. The local bridge on port 4747 was unavailable. No groot service was touched. Tool details can show only statuses/reasoning that the bridge actually sends; this pass does not reconstruct missing historical tool arguments/results. The separate Hermes live surface is unchanged.
