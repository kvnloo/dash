# elemental-ui basecolor maps

Generated with kvnloo/elemental-ui (GPL-3.0-only) at its default branch:
`python3 tools/elemental.py generate --size 256 --out <dir>`, then `<material>/basecolor.png` copied here
as `<material>.png` for basalt, slate and limestone. `bun scripts/build-themed-assets.ts` inlines them into
`app/src/components/themed/elemental-textures.generated.ts`.
